# VTech - Premium Glass Mousepads & Gaming Sleeves

Benvenuto nel repository del sito web e-commerce specializzato in mousepad in vetro temperato ad altissime prestazioni e maniche (sleeves) da gaming professionali.

## Descrizione del Progetto

Questo progetto è un sito web e-commerce moderno e responsive, sviluppato per offrire un'esperienza utente premium e veloce. Il catalogo prodotti comprende mousepad in vetro dal design innovativo e sleeves per migliorare l'attrito e le performance di gioco.

## Struttura del Sito

Il sito è organizzato con una solida architettura front-end:
- `index.html`: Homepage dinamica con video promozionali e prodotti in evidenza.
- `catalogo.html`: Catalogo completo dei prodotti.
- `account.html`: Area riservata per l'utente.
- Pagine informative: `chi-siamo.html`, `contattaci.html`.
- Pagine legali: `privacy.html`, `termini.html`.
- `assets/`, `css/`, `js/`: Cartelle contenenti rispettivamente risorse multimediali, fogli di stile e script di logica.

## Tecnologie Utilizzate

- **HTML5**: Struttura semantica e best practice SEO.
- **CSS3**: Design system custom con variabili, flexbox, grid e animazioni per un'interfaccia utente accattivante (Vanilla CSS).
- **JavaScript (ES6+)**: Logica del front-end, gestione dinamica del DOM.

## Come visualizzare il progetto in locale

1. Clona il repository sul tuo computer:
   ```bash
   git clone <URL-DEL-TUO-REPOSITORY>
   ```
2. Naviga all'interno della cartella del progetto.
3. Apri il file `index.html` nel tuo browser preferito. 
4. *Consigliato:* Utilizza l'estensione "Live Server" su Visual Studio Code per avere il ricaricamento automatico della pagina durante le modifiche.
